# NXTAGE

전직 아이돌의 사회 복귀를 돕는 AI 진로 전환 플랫폼. 나무위키 텍스트와 설문 답변을 분석해 (1) 성향 카드, (2) 직무별 포트폴리오, (3) 직업 추천 Top 5, (4) 단계별 커리어 로드맵을 자동 생성합니다.

2026 해커톤 출품작 — 12시간 안에 구현된 MVP.

## 핵심 기능

1. **역량 진단 및 AI 포트폴리오 빌더** — 위키 텍스트 + 8문항 설문 → 8차원 성향 점수 + 직무별 포트폴리오
2. **맞춤형 직업 추천 및 로드맵** — 10개 직업 풀에서 Top 5 매칭 + 4단계 진행 가이드 + 학습 자료 추천
3. **은퇴한 선배 아이돌 멘토링 커뮤니티** — Q&A 게시판 + 라이브 클래스 (별도 브랜치, DB 연동)

## 데모 사용법

1. 랜딩 페이지에서 "데모로 체험하기" 클릭
2. 자동으로 페르소나 양** (전직 6인조 걸그룹 멤버, 2017~2024 활동)의 답변이 채워진 상태로 진행
3. "분석 시작" 클릭 → 6초 후 결과 페이지

## 실제 위키 URL 분석 (선택)

데모 페르소나 외에, 본인의 나무위키 또는 위키백과 URL을 입력하면 활동 기록 기반의 정확한 분석을 받을 수 있습니다.

1. 랜딩 페이지에서 "직접 입력하기" 클릭
2. Step 1에서 "본인 위키 URL" 항목에 URL 입력 (예: `https://namu.wiki/w/...`)
3. 8문항 설문 + 자유 서술 작성 후 "분석 시작"
4. AI가 위키 텍스트를 실시간 분석해 결과 생성

## 기술 스택

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4 + shadcn/ui (base-ui)
- Anthropic Claude API (claude-sonnet-4-5) + Tool Use
- cheerio (위키 HTML 파싱)
- recharts (레이더 차트)
- Vercel Postgres (커뮤니티 DB, 별도 브랜치)

## 브랜치 구성

본 저장소는 발표 시연을 위해 두 모듈을 병렬 개발했으며, 통합은 발표 직후 진행됩니다.

| 브랜치 | 모듈 | 주요 기능 |
|---|---|---|
| `main` | AI 진단 코어 | 위키 분석, 성향 카드, 직업 추천, 로드맵 |
| `ui` | 커뮤니티 + DB | 로그인, 권한 분리, Q&A 작성, 라이브 클래스 |

두 모듈은 동일한 데이터 스키마를 공유하도록 설계되어 있습니다.

## 환경변수

`.env.local` 파일 생성 후:

```
ANTHROPIC_API_KEY=sk-ant-...
USE_MOCK=true
```

- `USE_MOCK=true`: mock 데이터 즉시 반환 (개발/시연용, 비용 0원)
- `USE_MOCK=false`: Claude API 실제 호출 (호출 1회 약 $0.10)

커뮤니티 기능을 사용하려면 `ui` 브랜치 체크아웃 후 추가 환경변수 설정 (Vercel Postgres 연결 정보) 필요.
